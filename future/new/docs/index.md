# Maryus Myary - GitHub Profile Dashboard

This repository acts as an interactive, production-ready GitHub Profile README. It is built using native **HTML**, **CSS**, and **SVG Animations** to ensure maximum fidelity, compatibility, and interactivity directly within GitHub's ecosystem.

## Architecture
The visual architecture utilizes a hub-and-spoke model, centered around a flat vector avatar. Surrounding the avatar are 16 interconnected Service Cards, mimicking a microservices dashboard.

## Technologies Included
- **Languages:** Python, JavaScript, TypeScript, Go
- **Frameworks:** Django, FastAPI, DRF, Celery
- **Data:** PostgreSQL, Redis, MongoDB, Elasticsearch
- **DevOps & Cloud:** Docker, Kubernetes, Terraform, Nginx
- **Monitoring:** Prometheus, Grafana
- **Design:** SVG, CSS3, Glassmorphism, Cyberpunk Aesthetic

## Animations
All visual effects in this dashboard are driven by **native CSS Keyframes** and **SMIL (SVG animations)** to ensure 60FPS fluidity. 
- **Data Lines:** Flowing dashed paths to represent real-time data streaming.
- **Pulse Rings:** A central glowing orb that scales and fades to mimic a live active core.
- **Health LEDs:** Status indicators blink synchronously to indicate service health (ONLINE/HEALTHY).
- **Charts:** The statistic SVG charts animate from 0 to 100% on load.

## Compatibility
This layout is fully responsive.
- **Desktop:** Displays as the full hub-and-spoke architecture.
- **Mobile/Tablet:** Automatically stacks into a vertical, scrollable feed, maintaining all glassmorphism effects and data points.
